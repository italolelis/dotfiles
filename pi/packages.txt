# pi extension packages — declarative manifest
#
# Mirrors the "packages" array in ~/.pi/agent/settings.json.
# install.sh reads this file and runs `pi install <spec>` for anything missing,
# so a fresh machine ends up with the same extension set as this one.
#
# Format: one package spec per line (npm:, git:, https://, or a path).
# Lines starting with # and blank lines are ignored.
# Leave specs unversioned so `pi update --extensions` can keep them current.
#
# After adding/removing an extension locally, print the live set and reconcile
# this file by hand:
#   pi list | grep -oE '(npm|git|https?):[^ ]+'
